🔒 Firebase needs one-time setup before uploads can work.
In the Firebase console (console.firebase.google.com → eri-fam project):
1 · Build → Storage → Get started — creates the storage bucket (needs the Blaze pay-as-you-go plan; your library is bigger than the free 5 GB anyway).
2 · Build → Authentication → Sign-in method — enable Email/Password, and under Users add your admin account if it isn't there.
3 · Deploy the security rules (already written, in the ERI-FAM folder): run npx firebase-tools login then npx firebase-tools deploy --only firestore:rules,storage.
Then come back here and press Start Upload again.
